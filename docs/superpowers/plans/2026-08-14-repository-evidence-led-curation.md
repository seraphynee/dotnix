# Repository Evidence-Led Curation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove transient repository residue and clarify source ownership without changing any evaluated system, user, package, secret, or Den aspect behavior.

**Architecture:** Keep the current category-grouped Den module tree intact. Curate the repository around three explicit boundaries: active declarative source, durable documentation, and ignored local execution state; make only semantic path renames, a recursive import-tree file move, redundant CI removal, and comment-only cleanup inside the active tree.

**Tech Stack:** Nix Flakes, vic/den, import-tree, NixOS, nix-darwin, Home Manager, sops-nix, Devenv, treefmt, just, GitHub Actions, Jujutsu (`jj`).

## Global Constraints

- Use only modern Nix CLI commands and flake references; do not use `nix-shell`, `nix-env`, `nix-channel`, or legacy channel workflows.
- Use Jujutsu for local version control, do not use Git as a fallback, and never contact the upstream repository.
- Preserve every Den aspect path and every angle-bracket aspect include.
- Preserve all packages, settings, secrets, generated configuration, host membership, user configuration, and platform behavior.
- Do not activate, delete, or relocate dormant configuration in `macos/`, `templates/empty/`, or unwired `dots/config/` paths.
- Do not remove unused-looking Den helpers or consolidate host/user include lists.
- Do not consolidate Devenv and the flake-native development shell.
- Use `apply_patch` for repository content edits and preserve unrelated working-copy changes.
- Treat a check that fails before the refactor as a baseline limitation; its final failure must match and no additional failure is acceptable.
- Each implementation task ends with a local `jj commit`; no push, fetch, bookmark update, or other upstream operation is authorized.

- Add an atomic Den aspect to the matching semantic category under `modules/`.
